Handyman service discovery and booking management API for HandyNear.

List all available handymen

query Parameters
serviceCategory
string
Example: serviceCategory=Plumbing

Filter providers by specific trade or skill category.

available
boolean
Example: available=true

Filter only handymen currently accepting jobs.

Responses

Local development server

http://localhost:5000/api/handymen
